CHAPTER 3: SYSTEM DESIGN

This chapter presents the detailed design of the News Management System (TONIA), including system architecture, UML diagrams, and data flow analysis. The system integrates a React-based frontend, an Appwrite backend for data management and authentication, and a Flask-based AI service for fake news detection.

3.1 System Architecture

The system follows a three-tier architecture:

1. Presentation Layer (Frontend): React application with TypeScript, using Vite for build tooling and Tailwind CSS for styling.

2. Application Layer (Backend): Appwrite cloud platform handling authentication, database operations, and file storage.

3. Data Layer: Appwrite database for storing user data, articles, and metadata. AI model stored as pickle file in the Flask service.

4. AI Service Layer: Separate Flask microservice for fake news detection using machine learning.

[AI Service (Flask)] --> [ML Model (Naive Bayes)]

3.4 Sequence Diagram

Sequence for Publishing News:

1. Writer logs in
2. Writer submits news
3. System sends to AI for fact check
4. Editor reviews
5. Editor publishes

Sequence Diagram (ASCII):

Writer -> AuthContext: login()
AuthContext -> Appwrite: authenticate
Appwrite --> AuthContext: token
AuthContext --> Writer: logged in

Writer -> Dashboard: submitNews(article)
Dashboard -> Appwrite: save draft
Appwrite --> Dashboard: saved

Dashboard -> FakeNewsDetector: detect(content)
FakeNewsDetector -> AI Service: POST /detect
AI Service --> FakeNewsDetector: result
FakeNewsDetector --> Dashboard: score

Editor -> Dashboard: review(article)
Dashboard -> Appwrite: update status
Appwrite --> Dashboard: updated

Editor -> Dashboard: publish(article)
Dashboard -> Appwrite: publish
Appwrite --> Dashboard: published

3.8 Flowchart of Fake News Detection Algorithm

Algorithm Steps:
1. Receive text input
2. Preprocess text (TF-IDF vectorization)
3. Load trained model
4. Predict class (REAL/FAKE)
5. Calculate reliability score
6. Analyze sentiment
7. Check for trigger words
8. Generate explanation
9. Return result
