CHAPTER 3: SYSTEM DESIGN

This chapter presents the design of the News Management System (TONIA), including its architecture, functional behavior, data flow, database structure, and algorithmic logic. The system is designed as a web-based news management platform that combines content management, role-based access control, and AI-powered fake news detection. It uses a React frontend, Appwrite Cloud for authentication and database services, and a Flask-based machine learning service for fact checking.

3.1 System Architecture

The proposed system follows a layered architecture made up of four main parts:

1. Presentation Layer: The user interface is developed with React, TypeScript, and Vite. This layer handles public pages, dashboard pages, and user interaction.

2. Application and Service Layer: Appwrite Cloud manages authentication, database operations, file storage, and access permissions, while the Flask service handles fake news detection and proofreading requests.

3. Data Layer: Appwrite collections store articles, comments, ratings, notifications, user metadata, and audit logs. Uploaded images are stored in an Appwrite storage bucket.

4. AI Layer: A separate Flask microservice loads a trained machine learning model and returns prediction results for submitted text.

     v

3.4 Sequence Diagram

Sequence for Submitting and Reviewing News:

1. Writer logs in.
2. Writer submits an article.
3. The system stores the article as a draft or pending item in Appwrite.
4. The system sends the article text to the AI service for analysis.
5. The AI service returns a credibility score and classification.
6. The editor reviews the article and checks the AI result.
7. The editor approves, rejects, or requests changes.
8. Approved articles are published to the public site.

Sequence Diagram (ASCII):

Writer -> AuthContext: login()
AuthContext -> Appwrite: authenticate
Appwrite --> AuthContext: session
AuthContext --> Writer: logged in

Writer -> Dashboard: submitArticle()
Dashboard -> Appwrite: create article
Appwrite --> Dashboard: saved

Dashboard -> Flask AI Service: POST /detect
Flask AI Service --> Dashboard: score, label, explanation

Editor -> Dashboard: review(article)
Dashboard -> Appwrite: update status
Appwrite --> Dashboard: updated

Editor -> Dashboard: publish(article)
Dashboard -> Appwrite: set status to PUBLISHED
Appwrite --> Dashboard: published

3.8 Flowchart of Fake News Detection Algorithm

1. Receive text input
2. Clean and preprocess the text
3. Convert text to TF-IDF features
4. Load the trained machine learning model
5. Predict class label
6. Calculate credibility score
7. Generate explanation
8. Return result to the frontend
