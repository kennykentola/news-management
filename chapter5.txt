CHAPTER FIVE
SUMMARY, CONCLUSION, AND RECOMMENDATIONS

5.1 Introduction
This chapter presents the summary of the News Management System (TONIA), the conclusion drawn from its development, and recommendations for further improvement. It also highlights the achievements of the project and the limitations observed during implementation.

5.2 Summary of the Project
The News Management System was developed to provide a digital platform for managing news content, supporting editorial workflows, and improving the reliability of published information through AI-based fake news detection. The project combines a React frontend, Appwrite backend services, and a Flask-based machine learning service.

The system allows users to register, log in, browse news, submit articles, review content, and publish approved stories. It also provides a fact-checking interface that evaluates text and returns a prediction on whether the content is likely real or fake.

The application was designed with role-based access control so that each user category has access to only the features relevant to its responsibilities. Writers can submit articles, editors can review and approve content, administrators can manage users and monitor activity, and general readers can access public news pages.

5.3 Conclusion
The development of the News Management System demonstrates that modern web technologies can be combined with machine learning to create a useful and practical news management platform. The system provides a structured workflow for handling articles and adds an intelligent layer of verification to help reduce the spread of misleading information.

The modular architecture of the project made it possible to separate the frontend, backend, and AI service into distinct components. This improves maintainability and makes future enhancement easier. The implementation also showed that Appwrite Cloud and Flask can work effectively together in a web-based information management system.

In conclusion, the project achieved its purpose of building a functional platform for news publication and fake news detection. It serves as a helpful tool for improving editorial decision-making and promoting more responsible news processing.

5.4 Limitations of the System
Although the system is functional, some limitations were observed during development and testing.

1. The fake news detection model depends heavily on the quality and size of the training dataset.

2. The system currently focuses mainly on text-based analysis and does not process images, audio, or video content.

3. Internet connectivity is required for communication with Appwrite Cloud and the AI service.

4. The prediction result from the AI model should still be reviewed by humans before final publication.

5. More advanced analytics and editorial workflows can still be added in future versions.

5.5 Recommendations
Based on the results of the project, the following recommendations are made for future development:

1. The dataset should be expanded with more recent and diverse news samples to improve model accuracy.

2. The fake news detection model should be upgraded with more advanced natural language processing techniques.

3. Support for multimedia fact checking should be added to handle images, video, and audio content.

4. More detailed dashboard analytics should be included to show article performance, user activity, and detection trends.

5. The notification system should be improved with email and mobile push notification support.

6. Additional language support should be introduced so that the platform can serve a wider audience.

5.6 Final Remarks
The News Management System is a practical application of web development and artificial intelligence in the area of digital journalism. It shows how technology can be used to support editorial work, improve news management, and encourage more accurate information sharing.

With further refinement, the system can become a more powerful platform for managing news and supporting fact checking in real-world environments.
